# Dra. Vitória — Landing Page Cinematográfica

Demonstração fictícia de uma landing page para acompanhamento de emagrecimento com direção visual cinematográfica, scrollmovie, profundidade e movimento ligado ao scroll.

## Executar localmente

Requisitos: Node.js 18+ e npm.

```bash
npm install
npm run dev
```

Depois, abra a URL exibida pelo Vite, normalmente `http://localhost:3000`.

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `index.html`: estrutura semântica e conteúdo da landing page.
- `src/styles.css`: sistema visual, responsividade, profundidade e cenas cinematográficas.
- `src/main.js`: scrollmovie, câmera virtual, HUD, menu e validação do formulário.
- `public/`: favicon e manifesto de rotas.

O formulário é apenas uma simulação. Nenhum dado é enviado ou armazenado.
